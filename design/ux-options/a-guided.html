    This is how applications reach you today.

    Someone applieson the careers website
    →
    You copy it into Excelby hand, one by one
    →
    You update each statusby hand, from memory

    Because it all lives in one big file that nothing checks, the file slowly stops matching reality. For example:

    • Someone who already works here is still marked "to contact".
    • Someone who left gets a call about a new job.
    • The same person appears twice, because they applied for two jobs.

    The idea: one list that fills itself and checks itself.

    Instead of copying into Excel, every application lands in one shared list on its own. Each person exists once, with their whole history.

    We suggest five changes. Each one fixes one problem. You can take one, some, or all.

    Change 1 of 5

    No more copying, and no more duplicates.

    The problem
    Every application is copied into Excel by hand, and the same person can end up in two rows with two different statuses.
    What changes
    Applications appear in one shared list on their own. If the same person applies again, it is added to their existing record. People who work here are never in your call list.
    What it takes
    Bigger jobabout 5 to 8 weeks
    How does it work behind the scenes?

    A small add-on on your careers website sends each new application to the list. Your existing Excel is imported once, and you confirm possible duplicates before anything is merged. Candidates see no change.

    Change 2 of 5

    Applications that already tell you what you need.

    The problem
    The form asks for name, email, phone and a CV. Language level, city and start date are hidden inside the CV, so you read every one.
    What changes
    The form asks four more short questions. You can sort and filter by language, level and city straight away. Every applicant also gets a "we received it" email.
    What it takes
    Small jobabout 1 to 2 weeks
    Anything else in this change?

    The job ads become real text under the poster image, so phones, translation tools and Google can read them. We also fix a few typos on the careers site.
